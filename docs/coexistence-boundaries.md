# 共存の制約とJibunKitの未対応

更新日: 2026-09-12。0.6.0公開後も1.0未達。基準は、JibunKitを知って開発を始めれば幅広いSwiftアプリを機能を削らず共存させられること。サンプルの成功は接続の部分的な証拠であり、完成基準の上限ではない。

## 1.0.0の上位完成基準

> JibunKitへ統合した結果、独立アプリならOSやアプリ境界によって得られていた隔離・調停・所有権管理が失われるなら、その差分をJibunKitが可能な範囲で補う。

「可能な範囲」は、対象OS・署名・プロセス構成で技術的に実現できる範囲を指す。実装の複雑さ、未要求、使用例やサンプルの不在を不可能の根拠にしない。費用や作業量によって実装順序を変えることはあっても、それだけで完成条件から外さない。

対象は、JibunKitを知ったうえで開発する幅広いSwiftアプリ。既存アプリの無修正移植や、SideStoreに依存する制限の全面解除を求めるものではない。明示的な共有は許容するが、統合しただけで所有者や状態が混ざることを既定動作にしない。

## 各領域の必須評価

1. **独立時の境界**: 同じOS・署名条件で独立アプリとして動く場合、OS・アプリ・プロセス・scene・extensionのどの境界が何を担うかを特定する。独立アプリ側で既に必要な処理をOSの保証と取り違えない。
2. **統合で失う差分**: 分離されていた識別子、保存状態、イベント配送、資源要求、タスク寿命、停止/復帰などのうち、統合で何が共有・曖昧化されるかを記録する。
3. **補完する契約と実装**: 所有者の登録、取得/解放、競合時の結果、取消・中断・復帰、必要な診断を定める。Feature別のhost分岐や他Featureの内部理解を通常手順にしない。
4. **残る制約と根拠**: 補えない差分について、該当API、OS/署名条件、再現結果を示す。根拠未確認は「未調査」、実装がないものは「未対応」とする。
5. **差分を補えた証拠**: 独立に作る複数Featureの同時要求、片方の取消・終了・失敗、他方の継続、中断後の復帰を確認する。単独成功や登録APIの存在だけでは合格にしない。

## 完了と未達の判定

- 各差分の状態は「補完済み・検証済み」「補完不要（既存境界が維持される根拠あり）」「技術的に補完不能（根拠・影響・可能な緩和策あり）」「未対応」「未調査」に分ける。
- 未対応・未調査を残した領域を、複雑さや未要求を理由に合格扱いしない。技術的に補完不能とする項目も、その範囲で可能な調停や被害軽減まで省略しない。
- 必要な補完が実装・検証され、残存制約の技術的根拠と開発者への影響が説明できたときに1.0を判断する。下の領域一覧は調査の入口であり、リスト外の差分を免除するものではない。
- サンプルは検証手段であり、基盤への着手条件ではない。正しく接続したFeature同士の干渉は基盤の責任として扱い、Feature固有の業務処理の誤りを修復する責任とは区別する。

## 外部根拠

- [AVAudioSession](https://developer.apple.com/documentation/avfaudio/avaudiosession): アプリの音声sessionはsingleton。だから調停が必要なのであり、複数Feature利用が不可能とはしない。
- [Choosing Background Strategies](https://developer.apple.com/documentation/BackgroundTasks/choosing-background-strategies-for-your-app): OSが実行機会を判断。登録とFeatureへの配送はアプリ側の責任。
- [App extensionの構造](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/ExtensionOverview.html): 本体とextensionを区別し、process共有の説明を対象に合わせる。

## 差分台帳の記録形式

各領域・差分ごとに「独立時の保証と主体 → 統合による喪失 → 補完契約/実装 → 競合・終了・復帰の検証 → 残存制約/根拠 → 状態/残タスク」を記録する。初期棚卸し表だけではこの評価を終えたことにならない。

例: 片方のFeatureを閉じたとき、そのFeatureが所有する処理だけを停止・解放し、他方の処理を継続できることを確認する。全プロセスのクラッシュ隔離を再現できないことを理由に、所有者単位の取消まで対象外にしない。
