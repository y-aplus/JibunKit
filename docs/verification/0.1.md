# 0.1 検証記録

更新日: 2026-09-04

**状態:** JibunKitへの改名後を再検証中。本体`com.jibunkit.app`、Widget `com.jibunkit.app.Widget`、App Group `group.com.jibunkit.shared`へ変更し、WSLの全11テスト、ローカルiOSビルド、`JibunKit.ipa`のZIP構造とbundle ID検査に合格した。改名後の[Actions run `33844972938`](https://github.com/y-aplus/JibunKit/actions/runs/33844972938)でも、全11テスト、Xcode 26.6ビルド、公式App Intentsメタデータ、本体・Widget、識別子、App Group、署名構造、IPA整合性、artifact uploadに合格した。同runのIPAをSideStoreで初回導入し、F1〜F5に合格した。別ビルドへの上書き更新と署名更新は未実施である。

旧称・旧識別子ではiPhone 16e／iOS 26.6／SideStore 0.6.3上でF1〜F7に合格した。ただしbundle IDとApp Groupを変更したJibunKitは別アプリであり、その実機結果を現在の版の合格として流用しない。旧アプリの保存値を移行する仕様も設けない。

## 改名前の実機履歴

旧称・旧識別子のActions IPAでは、次を確認した。この履歴は機能とビルド経路の先行証拠であり、JibunKit識別子の最終承認には使わない。

- アプリ再起動後の保存値、画面とShortcutsからの加算、3サイズのWidget表示。
- カウンターとリマインダーの独立保存、通知許可の拒否と許可、foregroundと終了状態からの通知タップ。
- 同一識別子での上書き更新とSideStore署名更新後の保存値・Shortcuts・Widget・通知。
- クリーンなGitHub-hosted macOS runnerでのXcode 26.6ビルド、公式App Intentsメタデータ、Widget、署名構造、IPA整合性。
