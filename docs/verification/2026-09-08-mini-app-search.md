# ミニアプリ一覧の検索

更新日: 2026-09-08

複数のFeatureを組み込んだ構成で目的のアプリを探すため、標準のSwiftUI検索欄を追加した。表示名または安定IDの部分一致で絞り込み、空欄・空白だけなら全件を表示する。表示順はRegistryの順序を維持し、検索対象は一覧のメタデータだけである。該当なしは標準の検索結果なし表示にする。

ホストの既存NavigationLinkを使い、検索結果から同じFeature画面へ進む。Featureの保存・通知・バックアップ形式は変更しない。新しい共通サービスやFeature側の検索対応は要求しない。

UIテストへ大文字のID検索、他アプリの非表示、結果からの起動、該当なし、検索語削除で全件復帰を追加した。差分検査は成功、iOSビルドとUI実行はCIへ送る。先行URL遷移のCIが失敗した場合、同じ一覧・navigationに影響する問題か確認して修正を優先する。
