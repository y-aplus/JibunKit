# Records 中間実機確認

専用ブランチ codex/records-device-check は f10deb6 の通常ホストへ参照Integrationを追加する。Counter/ReminderのID・保存先は変更せず、Recordsを独立したrecords保存先へ接続する。テスト専用のExample起動引数・fixture/control UIは含めない。mainへはマージしない。

自動検証ではJSON/ZIP往復とRecords添付取込み・行表示が成功し、Quick Look表示は未解決。Simulatorの成否を実機結果に読み替えない。

## 一度に確認する項目

1. IPAをいつもの方法でインストールし、「記録」を開いてテスト用の記録を一件作る。
2. 詳細の「ファイルを添付」から小さなtxt/PDF/画像を選び、添付名が表示されるか確認する。
3. 添付名を押してプレビューが開くか確認する。開かない場合はそれだけ記録し、次へ進む。
4. アプリを終了・再起動し、記録と添付が残っているか確認する。
5. 添付行を左へスワイプし、削除キャンセルでは残ること、削除確定後は再起動しても消えていることを確認する。

結果は「取込み／プレビュー／再起動後保持／削除」の4項目で返せる。これは中間確認であり、v1.0最終確認ではない。
