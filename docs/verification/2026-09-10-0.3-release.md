# 0.3.0出荷候補

ユーザーの「ある程度やったらv0台のリリースも少し入れる」という2026-09-10の依頼に基づく中間版。現時点は候補準備中で、公開済みとはしない。1.0は未達。

## 候補の内容

本体/Widgetを0.3.0 build 4へ揃え、CIで両方の版一致を検査する。通常IPAはCounter/Reminder。Recordsは参照ソース、ZaikoとCI fixtureは配布対象外。

直前の製品sourceは`6a4d2fdd22f2f2f791cdc7ee9bb8ab10d1f967cc`。候補への変更はProject.swiftの版番号、CIの版検査、文書のみ。Runtime・通信・navigationの実装は変えない。候補のCIとIPAを取得後にrun/source/hashを追記する。
