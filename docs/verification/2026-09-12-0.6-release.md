# JibunKit 0.6.0公開検証

状態: 出荷候補の準備中。公開済みではない。

## 出荷境界

本体/Widgetを0.6.0 build 7とする。通常RegistryはCounter/Reminderのみ。
Zaikoのignoredローカルソースと、CI用のPackage/診断fixtureは組み込まない。
bundle ID・App Group・保存キー・既存Counter Intent識別子は変更しない。

候補はmain `2b06012e75a7b596d9410a28a558e2aea51be344`を基準に、版・CI期待値・文書だけを更新する。
共有refresh、Package翻訳とWidgetの接続を含む。v1.0の共存基準は未達。

成功後にIPA全entryの展開/CRC、version・ID・fixture非混入を確認し、source/tag/SHA-256を固定する。

## 未検証の境界

Controlや一般SDK/runtime globalsの共存などは台帳に残る。native BackgroundTasks fixtureの
compile-only成功をOS受付成功へ読み替えない。この版そのものの新しい実機確認はしていない。
