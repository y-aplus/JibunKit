### 8の照合手順（初期値から確認する場合）

JibunKitを一度完全終了して開き直す。P0 Aを開き、一覧へ戻ってP0 Bを開く。
画面の上の数値列がA、下がB。診断カウンターは起動ごとに初期化される。

1. Broadcast → Send A → Send B。両方state=running。Aはn=1/value=11、Bはn=1/value=22。
2. Stop A。Aはstate=stopped、ended=1、cleaned=1。Bはstate=runningのまま。
3. Broadcast。Aのnは1のまま、Bのnだけ2へ進む。
4. Fail next A start → Start A。Aはstate=failed、ended=2、cleaned=2。BroadcastでAのnは1のまま、Bのnだけ3へ進む。
5. 一覧へ戻ってP0 Aを開く。Aはstate=runningへ戻る。BroadcastでAのn=2、Bのn=4。

2〜5を通じてAのvalue=11、Bのvalue=22を保持し、Bはstate=running、ended=0、cleaned=0のまま。
開始回数gはこの手順ならAが1→2→3、Bが1。既に操作を繰り返した起動では絶対値が異なるので、初期値と比較する場合だけ冒頭の完全終了から始める。
