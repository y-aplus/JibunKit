## 最終統合レビューとCI境界

音声review2 `31d9a65`、撮影review2 `3da2833`と追補`06ece16`を取り込んだ。追補は同じreview2を修正したcommitのため、重複差分を再適用せず動画中断の追加分を統合した。音声SDK raw定数との照合、Now Playingの再帰停止拒否、native開始/終了のjoin、旧delegateの拒否、Feature同意の再検査、VisionKitの提示寿命と失敗表示をレビューした。

親側では音声付き撮影を共有AudioSessionへ接続した。互換profileでの共存と、非互換時に次回一度だけ承認する明示切替を実Featureへ接続し、橋渡しのnative target試験を追加した。音声解放失敗は成功とせず、明示復旧まで解放完了を待つ。操作開始は停止transaction中にbusyを返し、remote操作と停止joinの循環待ちを防ぐ。lifetimeの100ms再試行を解放完了通知へ置き換え、同時releaseと明示復旧の回帰を追加した。

撮影側は外部音声解放callbackにoperation generationを付け、次の撮影を誤停止しない試験を追加。写真のfinal errorをDataより優先し、停止中のnative再開を拒否する。写真取消時は要求を失敗で完了し遅着callbackを無視する。動画は中断時に部分成果の保存または失敗を確定し、自動で同じ録画を再開しない。動画previewは音声調停を迂回せず外部アプリへの共有で行う。

音声の競合同意拒否試験は互換要求を誤って競合としていたため、実際に非互換の既存ownerを配置して修正した。実Featureのlifetimeを通して片側停止時の他runtime/lease保持も検査する。これらSwift試験は追加・レビュー済みであり、まだ実行成功を意味しない。

状態遷移、互換/非互換要求、片側失敗・停止・取消、遅延callback、世代、他ownerの非初期値保持は自動試験へ置く。実Feature結線も検査し、fakeだけの成功で完了にしない。
