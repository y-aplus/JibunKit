## IPA and device check

The normal job's IPA was attached to the [`v1.1.0-check-20261009`](https://github.com/y-aplus/JibunKit/releases/tag/v1.1.0-check-20261009) prerelease: 5,258,095 bytes, SHA-256 `7fa004dfeb257392368550657f00c5e6cf12225335f09f2c7962ea6aff247732`, re-downloaded and matched. All 47 ZIP entries passed CRC. App `com.jibunkit.app`, Widget `com.jibunkit.app.Widget` and Share `com.jibunkit.app.Share` report 1.1.0/17. The app icon is present; no diagnostic Feature is included.

The owner installed it over the existing JibunKit on an iPhone and reported on 2026-10-10 that all of the following worked:

1. The new default icon on the Home Screen.
2. Counter and Reminder values kept after the overwrite install.
3. No bar at the bottom of a Feature; tapping “ミニアプリ” returns to the list.
4. Long-pressing “ミニアプリ” shows the menu and switches Features.
5. Home Screen quick actions open the selected Feature, both while JibunKit was running and after it was closed from the app switcher.

## Not verified on a device

The normal IPA contains only Counter and Reminder, which do not use icon badge counts, Spotlight "Search in App", `NSUserActivity` routing, `MiniAppExternalURL`, `scanCode` or the notification extensions. These are covered by core tests, native tests where listed above, and builds only. Earlier use of quick actions, Spotlight and code scanning in a derived host is the owner's evidence from that host and is not repeated here.

## Document review

Current statements of the release state were checked in README, CONTRIBUTING, build, compatibility, status, SideStore, updating and the coexistence ledger. The SideStore and updating guides still called 1.0.0 an unpublished candidate and were corrected. Guides changed in this release (scene navigation, capture, owned presentations, URL routing, static widgets, app-wide surfaces, on-device language models, adding a feature) were written or revised with the changes themselves.
